# Lordicon icons

Animated "System · Outline" icons by [Lordicon](https://lordicon.com/), used under the
[Lordicon free license](https://lordicon.com/licenses), which requires attribution. The
credit is shown in **Settings**.

Only icons marked free on lordicon.com are bundled. The Lottie JSON files were taken
unmodified from Lordicon's public [`lordicondev/ui-components`](https://github.com/lordicondev/ui-components)
repository (`shared/public/icons/`). They are excluded from this repository's own license and
remain Lordicon assets. They ship with the bundle, so local mode never fetches them from a CDN.
