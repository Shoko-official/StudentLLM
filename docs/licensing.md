# Licensing

This page states how StudentLLM is licensed, what third-party code and data it depends on, what the release bundles contain, and what the owner still has to decide. It was produced by an audit on 2026-10-31. Every non-trivial claim cites the page it was read on. Claims that could not be verified from a first-party source are marked **unverified**. This is not legal advice (see [the end of this page](#legal-note)).

## Summary

- StudentLLM's own code is released under the [MIT licence](../LICENSE).
- The desktop release bundles (`.deb`, NSIS `.exe`, `.dmg`) contain the Rust shell, the compiled web app and its fonts and icons. They do **not** contain Python, the sidecars, or any model weights. Every component in them is permissive or weak copyleft (MPL-2.0 files used unmodified).
- The optional sidecars (documents, speech, benchmarks) are installed by the user from the `requirements-*.txt` files. Today nothing redistributes them. If a future release bundles them, the items under [Before bundling a sidecar](#before-bundling-a-sidecar) apply.
- PyMuPDF (AGPL-3.0 or commercial) was **replaced** in the document sidecar by pdfminer.six (MIT) and pypdfium2 (Apache-2.0 or BSD-3-Clause). It is no longer a dependency.
- Lordicon animated icons (CC BY-ND 4.0 based, account-bound) were **removed** and replaced by Lucide (ISC).
- `npm run licenses:check:all` fails CI on a new strong-copyleft, non-commercial or unknown licence in the production npm tree, the Rust crates and every Python requirements file.

## Decision record: PyMuPDF

- **Finding.** The document sidecar imported `fitz` (PyMuPDF), listed in `requirements-local-documents.txt` as `PyMuPDF>=1.26,<2`. The official documentation states: "PyMuPDF and MuPDF are now available under both, open-source AGPL and commercial license agreements", and that users who cannot meet the AGPL should contact Artifex for a commercial licence ([PyMuPDF about page](https://pymupdf.readthedocs.io/en/latest/about.html)). The installed 1.28.2 package declares "Dual Licensed - GNU AFFERO GPL 3.0 OR Artifex Commercial License" in its own metadata, and the policy check rejects it.
- **Why it mattered.** The AGPL is a strong copyleft licence that also covers use over a network. A sidecar that is an HTTP service wrapping PyMuPDF, shipped with a product that is sold under MIT, would have had to be released under AGPL-compatible terms or be paid for. It was tolerable only because the sidecar was never redistributed.
- **Replacement.** pdfminer.six (MIT) for text and layout, pypdfium2 (Apache-2.0 or BSD-3-Clause, PDFium) for rendering scanned pages for RapidOCR. `pypdf` (BSD-3-Clause) was considered and not used: it extracts text but offers no layout or font information, which the formula grouping needs. Behaviour changes are listed in [local-documents.md](local-documents.md#differences-from-the-pymupdf-engine).
- **Option kept open.** If better PDF layout quality is needed later, a commercial PyMuPDF licence from Artifex is the alternative; it requires a purchase and a decision by the owner.

## Policy and tooling

| Command | What it does |
| --- | --- |
| `npm run licenses:check` | Reads `package-lock.json` and `cloud/package-lock.json` (production entries) and, when installed, `cargo metadata`. Fails on strong copyleft (GPL, AGPL, CC-BY-SA), non-commercial or unknown licences. |
| `npm run licenses:check:all` | Same, plus every `requirements-*.txt` resolved with `pip install --dry-run --report`, and requires Cargo. This is what CI runs (job "Licence policy"). |
| `npm run licenses:test` | Unit tests of the classifier (`scripts/license-policy.test.mjs`), including that a GPL or AGPL package fails and that PyMuPDF would be rejected. |
| `npm run licenses:notices` | Regenerates [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md) (npm and Rust summary, about 56 KiB). CI runs `node scripts/generate-third-party-notices.mjs --check`, which fails when a lockfile changed since the file was written. |
| Release workflow | Runs `generate-third-party-notices.mjs --full` and attaches `THIRD_PARTY_LICENSES-<OS>.md` with every licence text to the draft release. |

An OR expression passes when one option is permissive (`MIT OR GPL-3.0-or-later` is treated as MIT). Weak copyleft (LGPL, MPL) passes and is listed. `scripts/license-policy.json` holds `overrides` (corrected metadata, each with evidence) and `exceptions` (an accepted risk with the reason it does not reach users). Adding an exception is a review decision.

The checks read declared metadata, not licence texts or code; they cannot catch a package that declares the wrong licence, copied code, or the contents of binary wheels. Those need the manual review recorded on this page.

## Before bundling a sidecar

If a release ever ships Python and the sidecars (see `docs/enterprise-readiness.md`, item B20), these become redistribution obligations:

1. **Document sidecar.** Ship the licence texts of pdfminer.six, pypdfium2 and its `BUILD_LICENSES`, RapidOCR plus `MODEL_LICENSES.md` and a "converted from PaddleOCR" note, and the FreeType credit line. Keep OpenCV's FFmpeg and Shapely's GEOS as separate replaceable libraries, include the LGPL-2.1 text, and give the corresponding source or a link. A frozen single-file executable makes the LGPL relinking requirement harder to meet; prefer an onedir layout. Consider replacing `opencv-python-headless` and `shapely` (RapidOCR dependencies) if those obligations are unwelcome.
2. **Speech sidecar.** Do not bundle the PyAV wheel as is. Options: build `av` against an LGPL-only FFmpeg, or decode audio outside Python with an LGPL FFmpeg build, or accept GPL obligations (not compatible with an MIT-only story). Check the NVIDIA cuDNN and Intel OpenMP terms for GPU builds.
3. **Models.** Whisper and RapidOCR weights are permissive. Ship the licence text with each model.
4. **Benchmarks.** Never bundle benchmark requirements (`html2text` is GPL-3.0).

## Owner decisions still open

1. **Commercial licensing route.** Staying MIT, open core, dual licence or source-available is a business decision (section 5 of `docs/enterprise-readiness.md`, on the `docs/enterprise-readiness` branch). None of the fixes here constrains it; relicensing later needs the consent of every contributor (no CLA or DCO exists yet).
2. **PDF quality versus licence.** Accept pdfminer.six (free, slower, glyph-box geometry), or buy a PyMuPDF commercial licence from Artifex for MuPDF speed and layout.
3. **Speech sidecar packaging.** Choose between an LGPL FFmpeg build, an external decoder, or leaving the sidecar user-installed (the status quo).
4. **Lordicon.** Keep Lucide (done), or buy a PRO licence if the animated icon style is wanted back (price and terms at lordicon.com).
5. **Benchmark claims.** Decide whether results on CRAG (CC BY-NC), FiQA and NFCorpus (non-commercial/academic), OmniDocBench (research only) and DocVQA (terms unknown) may appear in marketing; ask counsel, or drop those rows from public material.
6. **Missing statements.** Trademark and contribution terms (DCO or CLA), the licence of the WebView2 runtime for Windows redistribution, NVIDIA's hosted API trial terms (third-party summaries describe them as evaluation-only; the primary text was not retrieved) before relying on NIM for anything beyond benchmarks.
7. **Unverified items to close.** The CTranslate2 wheel's NVIDIA and Intel redistributables, the PyAV FFmpeg GPL status from PyAV itself, the RapidOCR classification model's card, `stop-sequencer`'s licence grant, SQLite's public-domain statement, and the MTRAG, Earnings-22, MUSAN and STSBenchmark dataset terms.

## Legal note

This page is an engineering audit built from public sources on the date above, not legal advice. Licence terms change, wheels and models are updated, and several items are marked unverified. A qualified lawyer should review it, the dependency list and the commercial licensing plan before StudentLLM is distributed commercially.
